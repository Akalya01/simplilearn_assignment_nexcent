# Nexcent Landing Page

Welcome to the **Nexcent Landing Page** project! This is a modern, responsive, and pixel-perfect B2B landing page built to demonstrate advanced front-end development skills and meticulous attention to UI/UX design.

## 🚀 Overview

This project takes a high-fidelity Figma design and translates it into a fully functional web application. Instead of relying on a generic template, this application was crafted carefully by breaking the design down into modular, reusable sections while maintaining a strict **data-driven architecture**.

All of the website's copy, images, and links are stored separately from the UI components. This ensures that the code remains clean, maintainable, and easy for non-developers (like a marketing team) to update.

## ✨ Key Features

- **Pixel-Perfect UI:** Exact design tokens (colors, font sizes, line heights, and padding) were extracted from Figma and applied using Tailwind CSS arbitrary values to ensure 100% fidelity to the original design.
- **Data-Driven Architecture:** All content is loaded dynamically from a central `content.json` file, demonstrating a strong separation of concerns between logic/layout and content.
- **Fluid Animations:** Integrated with Framer Motion to provide premium, subtle scroll-reveal animations and hover micro-interactions that make the site feel alive.
- **Fully Responsive:** Beautifully adapts to mobile, tablet, and desktop screens using modern CSS Grid and Flexbox techniques.
- **Image Optimization:** Logos and illustrations are handled with strict aspect ratio controls to ensure they never stretch or squish, regardless of the screen size.

## 🛠 Tech Stack

- **Framework:** [Next.js](https://nextjs.org/) (React Framework for production-grade applications)
- **Language:** [TypeScript](https://www.typescriptlang.org/) (For static typing and robust code maintainability)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/) (Utility-first CSS for rapid, exact styling)
- **Animations:** [Framer Motion](https://www.framer.com/motion/) (For production-ready React animations)
- **Icons:** [Lucide React](https://lucide.dev/) (For clean, scalable vector icons)
